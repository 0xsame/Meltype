# 報告された誤変換のコーパス

GitHub の issue から、「打ったもの (キーをそのまま)」と「期待した結果」を取り出したものです。
判定の作り方に関係なく、判定を変えるときに同じ物差しで比べられます (`--expect` にそのまま渡せます)。

```bash
dotnet run --project src/Meltype.Core.Tests -c Release -- --expect src/Meltype.Core.Tests/data/issue-cases.tsv /tmp/issue.json
```

## 集め方

- 全 issue (open / closed の両方、633 件) を対象に、テンプレートの「打ったもの (キーをそのまま)」と「期待した結果」が両方あるものを集める (174 件)
- 打ったものが英数字・記号だけのもの、期待がかな・カタカナ・英字だけのものを残す (79 件)
- 漢字を含む期待 (41 件) は、テストの変換器が Mozc を使わないため除く
- 打ったものに日本語が混ざるもの (21 件)、期待が記号だけのもの (31 件) も除く
- 同じ組は 1 回だけ (2 件)

自由記述の不具合・提案 (459 件) は、打ったものと期待した結果が分かれて書かれていないため自動では取り出せません。必要になったら、その報告を読んで手で足してください。

## いまの結果

| 条件 | 結果 |
|---|---|
| 74 件版 (ラベル `誤判定` だけから作ったもの)・#1148 の前 | 51/74 |
| 74 件版・#1148 のあと (いまの main) | 57/74 |
| **79 件版 (全 issue から作ったもの)・いまの main** | **61/79** |

`--expect` は、カタカナの期待をひらがなとして比べ、漢字を含む期待は英字の部分だけを比べます
(`Repro.Expect`)。このコーパスは上の条件で抜き出しているので、すべて「かな・カタカナ・英字」の比較になります。
